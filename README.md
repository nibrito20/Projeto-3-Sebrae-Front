## 🚀 Funcionalidades

- Visualização do mapa de calor de interações
- Dashboard de abandono e funil de jornadas
- Score de engajamento por cliente
- Alertas de comportamento atípico
- Análise de conclusão de serviços
- Timeline de sinais implícitos de insatisfação
- Taxa de retorno e padrões de retenção
